# 🎖️ English Level Test (영어 레벨 테스트)

지루하게 많은 문제를 풀 필요 없이, 각 단계별로 **5분간** 집중하여 테스트를 치르고 합격 시 다음 단계로 도전하는 싱글 페이지 영어 평가 웹 애플리케이션입니다.

👉 **[배포된 테스트 사이트 주소](https://tramper2.github.io/EngLevelTest/)**

---

## ✨ 주요 기능 및 특징

1. **⏱️ 5분 집중 타임아웃 & 도어 해금 시스템**
   - 각 스테이지마다 5분(300초)의 카운트다운 타이머가 실행됩니다.
   - 남은 시간이 60초 이하로 떨어지면 타이머가 붉게 점멸하며, 제한 시간이 끝나면 자동 제출 및 채점됩니다.
   - 10문제 중 70% 이상 정답률을 기록하면 합격하며, 상위 단계(초급 ➡️ 중급 ➡️ 고급)의 잠금이 해제됩니다.
2. **✍️ 실시간 한글 피드백 및 해설**
   - 문제를 풀고 제출할 때마다 정/오답 판정 및 상세한 해설을 한국어로 보여주어 즉각적인 학습이 가능합니다.
3. **💾 진행 상황 유지 (Local Storage)**
   - 브라우저 새로고침을 하거나 창을 닫아도 해금된 레벨 진척도가 기기에 안전하게 저장됩니다.
4. **📜 실시간 이름 반영 및 PDF/인쇄 최적화**
   - 최고 단계 합격 시 이름을 입력하면 실시간으로 영문 이름이 반영되는 수료증(Certificate)을 발급합니다.
   - 인쇄 버튼 클릭 시 다른 모든 화면 요소(버튼, 입력창, 배경 등)를 제외하고 오직 아름다운 이중 골드 프레임의 수료증 양식만 깔끔하게 규격화되어 출력 및 PDF 저장이 가능합니다.
5. **💎 프리미엄 UI 디자인 (Glassmorphism)**
   - 딥 블루-네이비-퍼플 그라데이션 기조의 고급스러운 다크 모드를 사용하며, 반투명 효과의 글래스모피즘 카드 레이아웃과 반응형 최적화를 지원합니다.

## 📂 폴더 구조

```text
EngLevelTest/
├── index.html            # SPA 웹 사이트 메인 구조
├── style.css             # 다크 테마, 모바일 반응형, 인쇄 스타일셋 정의
├── questions.js          # 초급/중급/고급 (각 10문제, 총 30문제) 문제 은행 DB
├── app.js                # 타이머, 채점, 로컬 스토리지 연동, 수료증 출력 핵심 로직
├── deploy.ps1            # Git 원격 저장소 업로드 및 Pages 자동 배포 스크립트
├── user_preferences.json # 사용자 한국어 설정 보존 파일
└── Doc/                  # 프로젝트 관련 아티팩트 문서
    ├── implementation_plan.md  # 시스템 아키텍처 및 구현 계획서
    ├── walkthrough.md          # 최종 구현 요약본 및 검증 가이드
    └── task.md                 # 세부 개발 마일스톤 및 완료 목록
```

## 🚀 실행 및 배포 방법

### 로컬 실행
- 본 저장소의 모든 파일을 내려받은 후, 브라우저에서 `index.html`을 실행하면 즉시 동작합니다. (서버 빌드가 불필요한 순수 HTML/CSS/Vanilla JS 구성입니다.)

### 깃허브 배포 자동화
- Windows 환경에서 PowerShell을 켜고 아래 명령어를 입력하면 `main` 브랜치 소스 백업 및 `gh-pages` 브랜치를 활용한 웹 배포가 원클릭으로 진행됩니다.
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\deploy.ps1
  ```
